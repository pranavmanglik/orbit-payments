# Payments architecture decisions

Architecture Decision Records (ADRs) document durable changes to the payments capability's public
contract, lifecycle, security model, dependencies, and delivery guarantees. The architecture guide
describes the current contract; an ADR records why a material choice was made and what alternatives
were considered.

No standalone ADRs have been recorded for this package yet. Add an ADR before merging a change that
materially alters its contract or guarantees. Use the [ADR template](template.md).
